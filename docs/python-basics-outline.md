# Python Basics outline

Basics and LeetCode share the approved question-outline component. Basics shows
the topic, such as Start a Python program, as its main heading. Each unique skill
has one letter in the part dropdown; repeat variations are numbered underneath.
Switching parts/variations preserves drafts and earns no credit.

There are 98 core syntax drills and six optional file/configuration/API projects.
The optional projects have a separate practiced count and are available after the
core groups in the Questions list. Collections precede loops, and independent
grid rows come later with comprehensions. New drills cover tuples, unpacking and
break. Ordered and same-unit mixed practice remain available.

Every Basics skill has a concise explanation and a common mistake. Syntax checks
now cover the explicitly requested constructs, and main-guard checks exercise
both importing and direct execution. Existing progress is preserved; rerunning
an old answer uses the current checks.

The unit-by-unit review, verification results and remaining release limits are
in [curriculum-audit.md](curriculum-audit.md).
