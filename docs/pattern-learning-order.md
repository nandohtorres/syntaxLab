# Recommended pattern learning order

The question bank now follows prerequisites instead of the order in which a
pattern first appeared in the original Blind 75 inventory. This is a teaching
path, not an objective difficulty rating for every learner or every question.

1. Array scans and running state.
2. Sets and dictionaries.
3. Stacks.
4. Two pointers and palindrome expansion.
5. Sliding windows.
6. Binary search.
7. Intervals.
8. Matrices.
9. Linked structures.
10. Trees and BSTs.
11. Heaps.
12. Graphs.
13. Backtracking and tries.
14. Bits.
15. DP and greedy reasoning.

The early groups establish loops, state, membership and ordered scans. Windows
combine dictionary counts with two pointers. Matrix and tree work precedes
general graph traversal and branching; DP comes after simpler state tracking.
Bits are a specialized later branch rather than a prerequisite for every topic.
The existing Python-foundation prerequisites still apply, such as functions,
node references and recursion before recursive tree/graph work.

The curated order satisfies all declared pattern dependencies in the existing
curriculum. Question order within each group is preserved; official question
numbers are identifiers, not a difficulty ranking. The 75 IDs, titles, checks
and saved progress remain intact. Practice progression follows this same path,
and entering LC #3 from the path begins its preparation steps.

This approach is informed by the repo's prerequisite metadata and
[NeetCode's guidance on learning patterns in an intuitive order](https://blog.neetcode.io/p/prepare-coding-interviews).
